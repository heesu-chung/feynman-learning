# Problem

I often read or watch material and feel that I understand it, but I cannot always explain it simply.

That means the knowledge is not fully internalized.

## Existing tools

ChatGPT:
- good for explanation
- weak for persistent structure and review history

Mind map:
- good for structure
- weak for explanation quality and feedback

Notion:
- good for storage
- weak for interactive understanding verification

Figma/FigJam:
- good for visual layout
- weak for learning feedback and state

## This project

Combines:
- explanation
- feedback
- concept graph
- review state
- storage
- optional Notion/Figma export
