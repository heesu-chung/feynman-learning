# Project Constitution

1. Understanding First: the product exists to help me understand difficult concepts.
2. Product and Learning Move Together: every task should improve the product or teach an intended engineering skill.
3. ConceptGraph is the Source of Truth.
4. Renderer, API, Notion, Figma, AWS are adapters.
5. Tests Define Completion.
6. Human Controls Merge.
7. Use Small Safe Sprints.
8. Do not build future infrastructure before the learning loop works.
9. Use pnpm only.
10. Keep the MVP working.
